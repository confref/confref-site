---
title: "Datasets"
lead: "Each source is a separate dataset with its own licence, versions and provenance."
---

The statements of each source are kept apart from what confref derives from them. A dataset is one named graph.
Published versions are not changed; each version has a description of its provenance. Each dataset page links the
files of its versions on archive.confref.org. The stable versions are in the SPARQL endpoint at
[labs.confref.org/sparql/](https://labs.confref.org/sparql/) (beta), one named graph per dataset.
